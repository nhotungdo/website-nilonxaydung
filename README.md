## 🚀 Giới Thiệu Dự Án

Dự án **Vật Liệu Xây Dựng & Nilon Lót Sàn** là một nền tảng thương mại điện tử hiện đại, được xây dựng với kiến trúc **Next.js App Router** tối ưu SEO và hiệu suất. Giao diện được thiết kế theo phong cách *Corporate / Modern*, mang lại sự chuyên nghiệp và độ tin cậy cao cho các nhà thầu, kỹ sư xây dựng.

## ✨ Tính Năng Nổi Bật

- ⚡ **Tốc Độ Vượt Trội:** Tối ưu hóa với Server Components của Next.js 15.
- 🎨 **Thiết Kế Đẹp Mắt:** Sử dụng Tailwind CSS với hệ thống Design System chuẩn mực, animation mượt mà.
- 📱 **Responsive Hoàn Hảo:** Giao diện thích ứng trên mọi thiết bị (Mobile, Tablet, Desktop).
- 🔍 **SEO Tối Ưu:** Metadata động cho từng trang sản phẩm và bài viết.
- 💬 **Tương Tác Nhanh:** Tích hợp nút gọi điện và Zalo trôi (Floating Buttons) tiện lợi.

## 🛠️ Cài Đặt & Chạy Dự Án

<details>
<summary><b>Nhấp để xem hướng dẫn chi tiết</b> 👈</summary>
<br>

1. **Clone repository:**
   ```bash
   git clone https://github.com/your-username/nilon-website.git
   ```

2. **Chuyển vào thư mục dự án:**
   ```bash
   cd website-nilonxaydung/nilon-website
   ```

3. **Cài đặt thư viện:**
   ```bash
   npm install
   ```

4. **Chạy server phát triển:**
   ```bash
   npm run dev
   ```

5. **Mở trình duyệt:**
   Truy cập `http://localhost:3000` để xem kết quả.
</details>

## 📂 Cấu Trúc Thư Mục

Dự án tuân theo chuẩn kiến trúc mạnh mẽ và dễ bảo trì:

```text
nilon-website/
├── app/               # Next.js App Router (Pages & API)
├── components/        # Reusable UI Components
├── sections/          # Page sections (Hero, Featured, etc.)
├── data/              # Mock data & Models
├── lib/               # Utilities & Helpers
├── public/            # Static assets
└── styles/            # Global CSS (Tailwind variables)
```
